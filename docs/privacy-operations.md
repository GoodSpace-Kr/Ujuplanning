## 보관과 삭제

문의는 FormSubmit을 거쳐 Gmail 메일함으로 전달된다. 사이트 자체 DB에는 저장하지 않는다. 이 변경은 공개 문서와 링크를 추가한 것이며 이메일 자동 삭제 기능을 추가하지 않는다. 운영자는 만료된 문의 이메일, 휴지통, 업무용 사본과 출력물을 확인하여 삭제·파기해야 한다. 외부 서비스의 백업·삭제 조건은 제공자 문서와 계약을 확인한다.

## 확인이 남은 실제 처리 정보

FormSubmit 공식 FAQ는 제출 정보 보관 기간을 30일로 안내하지만, 공개 개인정보 문서에는 처리 국가·보관 위치가 명시되어 있지 않다. 서버 IP로 국외 이전 국가를 추정하지 않는다. 공개 방침에도 이 확인 한계를 표시했다. FormSubmit, Google, Cloudflare의 실제 이용조건·위탁 관계·처리 국가·이전 시기와 방법·보유 기간·국외 이전 법적 근거를 운영자가 제공자와 확인한 후 방침을 보완해야 한다. 현재 문서를 법적 요건 충족에 대한 보증으로 간주하지 않는다.

## 동의와 방침 공개

처리방침 공개는 문의 수집·이용 동의 또는 국외 이전 동의를 받은 것과 다르다. 이 변경은 전송 흐름과 수집 근거를 변경하지 않는다. 문의 목적과 수집·보유 근거를 검토하여 필요한 동의 항목과 서버 검증을 별도로 마련해야 한다. 입력 항목·외부 서비스가 바뀌면 방침과 문의 폼 안내를 함께 갱신한다.
